# 💰 Expense Tracker

A modern, responsive personal finance web application designed to help users manage their daily expenses, control budgets, track savings, and build better financial habits.

🌐 **Live Demo:** https://expense-tracker-xjnv.onrender.com

## About the Project

Managing money becomes easier when you can clearly see where it goes. This Expense Tracker helps users record and organize their expenses, monitor their available balance, set category-wise budgets, and understand their spending patterns through visual analytics.

The goal of the application is not just to track expenses, but to **encourage better financial decisions, promote saving habits, and motivate users to stay within their budgets.**

## Features

- User registration & login
- Email OTP verification
- Salary & available balance management
- Add, edit & delete expenses
- Search, filter & sort expenses
- Interactive expense charts
- Category-wise budget limits & alerts
- Monthly financial insights
- Expense & budget notifications
- Dark & Light mode
- Export expenses as CSV/JSON
- Responsive design for mobile & desktop

## Tech Stack

**Frontend:** HTML5, EJS, CSS3, JavaScript, Chart.js

**Backend:** Node.js, Express.js

**Database:** SQLite

**Authentication & Email:** bcryptjs, Express Session, Resend

**Tools & Deployment:** Git, GitHub, VS Code, Render

## CRUD Operations
